# Yamlwrangler Dashboard Operator Overview

This repository contains the Kubernetes/OpenShift operator and the console
plugin image it installs.

## Goals

- Install the Yamlwrangler App Dashboard console plugin through an `AppDashboard`
  custom resource.
- Discover apps from labeled namespaces, deployments, and routes.
- Manage dashboard metadata through typed custom resources instead of hand-editing
  ConfigMaps.
- Support raw manifest installs for development and a real OLM
  CatalogSource/Subscription flow for OpenShift Installed Operators.

## Main APIs

- `AppDashboard`: cluster-scoped install resource for the console plugin.
- `DashboardAppGroup`: namespaced grouping/selecting API for related deployments.
- `DashboardNamespaceConfig`: namespaced API that generates and manages
  `dashboard-config-<namespace>`.
- `DashboardLink`: namespaced API for adding or editing one custom link for an app.

## Runtime Images

- Operator image: built from the repository root `Dockerfile`.
- Console plugin image: built from `console-plugin/Dockerfile`.
- OLM bundle image: generated by `build-and-deploy.sh --olm`.
- OLM catalog image: generated by `build-and-deploy.sh --olm`.

## Source Layout

- `api/v1alpha1/`: Go API types and deepcopy implementations.
- `controllers/`: reconciliation logic.
- `manifests/crds/`: CRDs for all dashboard APIs.
- `manifests/deploy/`: raw operator manifests and RBAC.
- `manifests/olm/`: OperatorGroup, CSV template, CatalogSource template, and Subscription template.
- `manifests/samples/`: sample custom resources.
- `console-plugin/`: OpenShift dynamic console plugin source.

## Verification

Use writable Go caches in sandboxed runs:

```bash
/usr/bin/env GOCACHE=/private/tmp/yamlwrangler-go-build-cache GOMODCACHE=/private/tmp/yamlwrangler-go-mod-cache go test ./...
```
